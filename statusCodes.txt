Basic status codes description in 2-3 lines

200 OK
The request was successful, and the server has returned the requested data.
This is the most common success response for GET, POST, PUT, and DELETE operations.

400 Bad Request
The server cannot process the request due to invalid syntax or malformed data.
Common causes include missing parameters, invalid JSON, or incorrect request format.

401 Unauthorized
The request requires authentication, and valid credentials were not provided.
Usually occurs when tokens are missing, expired, or invalid.

403 Forbidden
The client is authenticated but does not have permission to access the resource.
This happens when user roles or access rights are insufficient.

404 Not Found
The requested resource could not be found on the server.
Commonly occurs when the URL is incorrect or the resource does not exist.

500 Internal Server Error
A generic error indicating something went wrong on the server side.
Usually caused by unhandled exceptions or unexpected failures in backend logic.

502 Bad Gateway
The server received an invalid response from an upstream server.
Common in microservices when one service fails to communicate properly with another.

503 Service Unavailable
The server is currently unable to handle the request due to overload or maintenance.
Often temporary and may include a retry-after header.
